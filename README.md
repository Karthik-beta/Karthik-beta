## Maintaining

### [Blinkql](https://github.com/Karthik-beta/Blinkql) · [live](https://blinkql.vercel.app)

A SQL workbench that runs entirely in the browser. Open a CSV, Parquet or JSON file with millions of rows, query it in milliseconds, and the data never leaves your machine. No account, no server, no upload.

DuckDB-WASM · React · TypeScript

It's early and built in the open, with a public [roadmap](https://github.com/Karthik-beta/Blinkql/wiki/Roadmap-and-Milestones), scoped issues and a [contributing guide](https://github.com/Karthik-beta/Blinkql/blob/main/CONTRIBUTING.md). If you're looking for a way in, start with a [good first issue](https://github.com/Karthik-beta/Blinkql/issues?q=is%3Aopen+label%3A%22good+first+issue%22). I review PRs quickly.
