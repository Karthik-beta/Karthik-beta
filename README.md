## Maintaining

### [Blinkql](https://github.com/Karthik-beta/Blinkql)

An in-browser SQL workbench: open a CSV, Parquet or JSON file and query it on your own machine, with no upload. Every performance change is benchmarked and published.

TypeScript, React, DuckDB-WASM, Apache Arrow

[Try it](https://blinkql.karthik.nz) · [Case study](https://karthik.nz/work/blinkql)

It's early and built in the open, with a public [roadmap](https://github.com/Karthik-beta/Blinkql/wiki/Roadmap-and-Milestones), scoped issues and a [contributing guide](https://github.com/Karthik-beta/Blinkql/blob/main/CONTRIBUTING.md). If you're looking for a way in, start with a [good first issue](https://github.com/Karthik-beta/Blinkql/issues?q=is%3Aopen+label%3A%22good+first+issue%22). I review PRs quickly.

### [workclock](https://github.com/Karthik-beta/workclock)

Business-time arithmetic (working hours, SLAs, shifts, holidays and time zones) with a Rust core and bindings for Python and JavaScript. Published on crates.io, PyPI and npm.

Rust, Python (PyO3), WebAssembly, TypeScript

[Docs](https://workclock.karthik.nz/docs/) · [Case study](https://karthik.nz/work/workclock)
